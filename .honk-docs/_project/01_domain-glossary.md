# 01 — Domain Glossary

Este documento define los términos de negocio y conceptos clave del proyecto CodeNoFrontier.

## Glosario

| Término | Definición |
| :--- | :--- |
| **CodeNoFrontier** | Marca y concepto de la agencia de desarrollo, enfocada en soluciones tecnológicas sin límites geográficos ni técnicos. |
| **Web3D Hub** | El núcleo interactivo del sitio donde se presentan los servicios y capacidades técnicas a través de una experiencia 3D. |
| **Hangar Slider** | Componente de interfaz que permite al usuario navegar entre diferentes "módulos" o "modelos" en un entorno tridimensional. |
| **Model Viewer** | El componente encargado de renderizar un objeto 3D específico, permitiendo interacción y visualización detallada. |
| **Cinematic UI** | Estilo visual que utiliza efectos de post-procesado como grano de película, viñetas y scanlines para crear una atmósfera inmersiva. |
| **Contact Form** | Canal de comunicación principal entre el cliente potencial y la agencia, procesado mediante backend PHP. |
