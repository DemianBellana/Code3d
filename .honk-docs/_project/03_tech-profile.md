# 03 — Tech Profile

Perfil tecnológico y stack de desarrollo de CodeNoFrontier.

## Stack de Tecnologías

- **Lenguajes:**
  - Frontend: HTML5, CSS3, JavaScript (ES6+).
  - Backend: PHP 8.x.
- **Librerías Core:**
  - **Three.js:** Motor principal para la visualización 3D.
  - **PHPMailer:** Gestión de protocolos SMTP para el envío de correos.
- **Tipografía:**
  - Google Fonts (Bebas Neue, Outfit, DM Mono).

## Dependencias Críticas
- **Three.js (CDN/Local):** Sin esta librería, el Hub 3D no es funcional.
- **Soporte WebGL:** El navegador debe ser compatible con aceleración por hardware.
- **SMTP Server:** Acceso a servidor de correo (ej. Gmail SMTP) para el funcionamiento del formulario.
