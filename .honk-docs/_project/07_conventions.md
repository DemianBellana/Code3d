Convenciones operativas y de colaboración para el proyecto CodeNoFrontier.

## Estándares de Documentación
- Todos los cambios significativos en la arquitectura o el stack deben reflejarse en `.honk-docs/_project/`.
- El progreso de las tareas se documenta en la carpeta `features/` siguiendo el flujo HonkFlow.

## Design Systems
- **Colores:**
  - Background: `#04050a` (Deep Space)
  - Accent: `#ff3c3c` (Pulse Red)
  - Accent 2: `#00ffe0` (Cyan Glow)
  - Text: `#f5f4ff` (Off White)
- **Tipografía:**
  - Headings: `Bebas Neue`
  - Body: `Outfit`
  - Data/Tech: `DM Mono`

## Flujo de Trabajo
1. Identificar requerimiento.
2. Documentar en Feature Doc.
3. Implementar siguiendo los Code Standards.
4. Validar según QA Standards.
